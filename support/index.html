START WITH
THE SIGNAL.

Choose the symptom that matches what you see. Each check is safe to complete while parked—never troubleshoot while driving.

RoadCue will not start driving mode
  1. Confirm Location Services or GPS is turned on for the device.
  2. Give RoadCue location access while the app is in use, then tap Start Driving again.
  3. If access was previously denied, open the device settings from RoadCue’s setup prompt and change the permission manually.
  4. Close and reopen RoadCue after changing system permissions.
The status says foreground only

RoadCue can monitor while visible, but alerts may pause when another app is in front. Grant Always or Allow all the time location access using the instructions below.

A nearby camera did not trigger an alert

RoadCue only warns for records in its bundled snapshot when your direction is closing on the monitored approach. A camera behind you, on a parallel road, outside the current snapshot, or not published by the source authority may not alert.

If the direction and location should have matched, send a camera-data correction with the intersection and travel direction.

The alert is silent or too quiet
  1. Raise the device’s media volume while parked.
  2. Open RoadCue Settings → Sound and preview the selected crossing sound.
  3. Check whether audio is being routed to Bluetooth, a vehicle system, headphones, another navigation app, or an active phone call.
  4. On iPhone, test spoken alerts with silent mode off; the crossing chime is configured separately from platform-managed speech.
Speed, heading, or background updates stop
  1. Confirm Precise Location is enabled and move to an area with a clear GPS signal.
  2. Do not force-quit RoadCue during an active trip.
  3. On Android, allow background activity or unrestricted battery use if the device manufacturer suspends RoadCue.
  4. Stop driving mode, reopen the app, and start it again while parked.

KEEP THE
SIGNAL OPEN.

Background access lets RoadCue continue monitoring while navigation, rideshare, or delivery apps stay in front.

iPhone / iPadiOS & iPadOS
  1. Register RoadCue.Open RoadCue and tap Start Driving at least once so the Location row is available in Settings.
  2. Open Location settings.Go to Settings → Apps → RoadCue → Location. On earlier iOS versions, use Privacy & Security → Location Services → RoadCue.
  3. Select Always.Turn Precise Location on. If you previously chose Allow Once, change the setting manually before starting again.
  4. Confirm the status.Reopen RoadCue and verify that the monitoring status reports background protection.
AndroidRecent Android versions
  1. Open the app permission.Go to Settings → Apps → RoadCue → Permissions → Location.
  2. Allow all the time.Enable Use precise location. Some Android versions only show this option after RoadCue requests location once.
  3. Allow background activity.If alerts are suspended, open RoadCue’s Battery settings and choose Unrestricted or the equivalent manufacturer setting.
  4. Confirm the status.Start driving mode while parked and verify background monitoring. Android may show a persistent location-service notification.

Notification permission is optional. Denying notifications does not prevent RoadCue from starting location monitoring.

THE SNAPSHOT
CAN BE CORRECTED.

RoadCue 1.2.0 uses a reviewed, build-time snapshot of official Canadian sources. It is not live-updated on your phone, so corrections are verified before a future app update.

Request a data correction Opens a prepared email
Location

Exact intersection or road, city, and province.

Direction

The direction of travel for the monitored approach.

Camera type

Red-light, speed, combined, removed, or unknown.

Correction

What appears missing, incorrect, duplicated, or out of date.

Evidence

An official source link or clear supporting reference, when available.

Do not send photos taken while driving, licence plates, trip histories, or other unnecessary personal information. This inbox is not monitored for emergencies or legal advice.
