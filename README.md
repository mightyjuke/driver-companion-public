Static marketing website for RoadCue, built for GitHub Pages.

## Preview locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Publish

In the GitHub repository settings, set **Pages → Build and deployment → Source** to **Deploy from a branch**, then select `main` and `/ (root)`.

## Launch checklist

- Replace the pending Google Play state with its verified product-page URL when the listing is live.
- Recheck camera-record counts when the bundled source snapshot changes.
- Update canonical, Open Graph, sitemap, and structured-data URLs if a custom domain is attached.
